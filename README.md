# CMSC 198 Leptospirosis project

Build `main.tex` from this folder using pdfLaTeX, BibTeX, pdfLaTeX, pdfLaTeX (or `latexmk -pdf main.tex`).

- `preamble.tex`: instructor template packages, Letter paper, margins, and commands.
- `frontmatter/`: instructor title-page layout and abstract guidance.
- `chapters/`: chapter and section files; existing Chapter 2 content is retained.
- `appendices/`: appendix placeholders from the instructor template.
- `images/`: project images.
- `references.bib`: your own bibliography database; add entries and cite them with `\cite{key}`.

Replace the title, adviser, abstract, keywords, and sample resource persons before submission. The instructor’s placeholder chapter text, citation examples, Disney chart, timetable, and sample references are included as writing guides. Replace these examples with your own research before submission. Chapter 2 template guidance is in `chapters/chapter2/template-guidance.tex`; your existing literature and studies files are retained.
